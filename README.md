# KONOMI

好きな服を左右にスワイプし、好みの雰囲気と具体的な着こなしを見つけるモバイルファーストの試作アプリです。

## 現在できること

- プロジェクト専用に生成した30枚のコーデを「好き／興味なし」で選択
- 一つ前の回答へ戻る
- 好きな特徴をタグから集計
- 7種類のスタイルタイプから結果を表示
- 休日、通勤・通学、デート向けの基本コーデを表示
- 好きなコーデの保存と削除
- 追加候補の提案
- ブラウザ内への進捗保存
- PWAとしてホーム画面へ追加

## 起動方法

Node.js 20以上が必要です。追加パッケージのインストールは不要です。

```powershell
cd C:\Users\shota\konomi-app
npm.cmd start
```

ブラウザで `http://127.0.0.1:4173` を開きます。
