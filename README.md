# KONOMI

好きな服を左右にスワイプし、好みの雰囲気と具体的な着こなしを見つけるモバイルファーストの試作アプリです。

## 現在できること

- ニックネーム、年代、性別、利用シーン、予算、買い物エリアの初期設定
- プロジェクト専用に生成した54枚のコーデから、性別に合わせた写真を「好き／興味なし」で選択
- 一つ前の回答へ戻る
- 好きな特徴をタグから集計
- きれいめ、カジュアル、ストリート、韓国系、モード、古着、アメカジ、シティーボーイ、スポーティ、アウトドア、Y2Kなど13種類のスタイルタイプから結果を表示
- 休日、通勤・通学、デート向けの基本コーデを表示
- 好きなコーデの保存と削除
- 追加候補の提案
- 好み・性別・予算に合わせた実在商品の提案
- 買い物エリアと診断結果に合わせた服屋・古着店とGoogleマップの表示
- ブラウザ内への進捗保存
- PWAとしてホーム画面へ追加

## 起動方法

Node.js 20以上が必要です。追加パッケージのインストールは不要です。

```powershell
cd C:\Users\shota\konomi
npm.cmd start
```

ブラウザで `http://127.0.0.1:4173` を開きます。
