# KONOMI

好きな服を左右にスワイプし、好みの雰囲気と具体的な着こなしを見つけるモバイルファーストの試作アプリです。

## FashionCLIP 第1段階（任意接続）

ローカル／自前PythonでのFashionCLIP画像embedding API、登録写真の事前分析バッチ、出典・権利情報を保持するpgvectorスキーマ、任意のSupabase Auth＋RLS保存の準備を追加しました。既存PWAとブラウザ保存は維持しています。スワイプ時にはモデルを呼びません。

FashionCLIP実推論は成功し、104枚の実写真のembeddingを保存済みです。Supabase実保存は未完了で、設定は後回しです。第1段階の資料は [FASHIONCLIP_SETUP.md](FASHIONCLIP_SETUP.md) を参照してください。従量課金AI API／新しい有料サービスは導入していません。

第2段階では好みベクトル・cosine similarity推薦・70/20/10探索・多様な初期20枚・重複回避を追加しました。[FASHIONCLIP_STAGE2.md](FASHIONCLIP_STAGE2.md) に詳細があります。

第3段階ではSTYLE SCOREと履歴ベースの好み分析を追加しました。スコアは`round(50 × (cosine similarity + 1))`で0〜100へ変換した「好みとの近さ」で、センスや確率ではありません。like/dislike/skip件数、likeした実コーデ、根拠のあるタグ・カテゴリの件数を表示します。Supabase・追加パッケージ・有料APIは不要です。確認結果と制限は [FASHIONCLIP_STAGE3.md](FASHIONCLIP_STAGE3.md) を参照してください。

- 次のコーデ・STYLE SCOREは事前分析済みのFashionCLIP画像特徴を使用。タグ・カテゴリの傾向は写真に手動で付けたデータを実際のlikeから集計

- 11の専門ブランドを公式ページで調査し、取り扱いの根拠・確認日・リンクを表示

- 公式情報で確認できる地域の独立系ショップ、服屋・古着店候補とGoogleマップの表示
- Google Places接続後、地域の店舗と取得できた口コミから服の言及を調べて推薦（[設定手順](LOCAL_SHOPS_SETUP.md)）
- 表示する実写104枚の原典・撮影者・ライセンスを確認できるクレジット一覧

## 起動方法

PCでモバイルレイアウトを編集・確認するときは `http://127.0.0.1:4173/?layout=mobile&v=21` を開きます。実際のスマホ幅のiframe内でアプリが動き、320・390・430pxを切り替えられます。編集後はプレビュー上部の「更新」で再読み込み、「PC表示」で通常表示に戻ります。通常のローカル画面にも「スマホ表示」のリンクがあります。診断履歴は同じブラウザの保存を共有します。

Node.js 20以上が必要です。追加パッケージのインストールは不要です。

```powershell
cd C:\Users\shota\konomi
npm.cmd start
```

ブラウザで `http://127.0.0.1:4173` を開きます。

## 写真の権利管理

2026-10-06に従来78枚とは異なる実写をさらに26枚追加し、合計104枚になりました。単一方向の初回13枚に加え、追加診断では未回答の39枚を最大6枚ずつ比較できます。追加分の再取得は `node scripts/import-additional-outfits.cjs` で行えます。

表示写真はPexelsライセンスの実写コーデのみを使用し、写真ごとの原典、撮影者、対象方向、カテゴリーを `assets/photo-sources.json` に記録しています。詳しい選定基準と注意事項は `PHOTO_SOURCES.md`、ブラウザで見られる一覧は `credits.html` を参照してください。

## Pythonによる写真の色分析

Python 3.13とPillow 12.3を使い、診断写真の中央領域の配色をローカルで解析します。写真の外部送信はありません。背景や肌も含むため、服の自動認識ではなく推薦の補助点と結果画面の参考表示に使います。形や素材は既存の説明に基づく分析です。

このPCには `.python/python.exe` を導入済みです。`npm.cmd start` は起動前に写真を再解析します。手動更新は `npm.cmd run analyze:photos`、Pythonのテストは `npm.cmd run test:python` です。解析結果は `assets/photo-analysis.json` と `photo-analysis.js` に保存され、ブラウザは生成済みの結果を使います。

別のWindows PCでは `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/setup-python.ps1` でプロジェクト内にPythonを用意できます。通常のPython環境では `python -m pip install -r requirements.txt` を実行し、必要なら `KONOMI_PYTHON` に実行ファイルを指定してください。
